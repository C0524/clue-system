# Archive Scripts

These scripts are archived because they were used for temporary diagnostics or one-off maintenance.

- diag_fallback.js: Diagnostic SQL checks for fallback consultant behavior.
- extract.js: Extracted inline script block from index.html during troubleshooting.
- find_template.py: Utility to scan template tag balance in index.html.
- run_migration.js: One-off visitStatus migration helper with backup table creation.
- fix_migration_adj.js: One-off migration adjustment script for visitStatus correction.
- tmp_vue_script.js: Temporary extracted Vue script snapshot.

Notes:
- They are not part of the runtime startup path.
- Keep them for historical reference only.
- If reusing them, review and update before execution.
